# InvoTracker MVP starter

A real Spring Boot + MySQL starter for a multipurpose invoice tracking website. This is an initial implementation, not a production-certified product.

## Implemented in this starter
- Business account registration and login with BCrypt password hashing.
- Session-based authentication and CSRF token support for browser requests.
- MySQL-backed users and invoices.
- Invoice create, list, update API, cancellation API, payment recording, and dashboard summary.
- Per-owner invoice queries to prevent one logged-in user from viewing another user's invoices.
- Single-page frontend integrated with the backend for registration/login, invoice creation, listing, search, dashboard metrics, payment recording and cancellation.
- Unit tests for payment balance/status rules.

## Not yet implemented
- Customer/supplier master records and line items.
- Persistent payment ledger (current starter stores cumulative paid amount only).
- Full immutable audit log, PDF generation, email reminders, OCR/webcam capture.
- Password reset, email verification, MFA, roles beyond one user role, rate limiting and advanced security review.
- Production migration management, backup/restore workflow and deployment configuration.
- End-to-end browser tests and multi-tenant penetration testing.

## Requirements on Windows
- JDK 21 (not just a JRE)
- Maven 3.9+ (or use the Maven wrapper generated by your IDE)
- MySQL Server 8+
- IntelliJ IDEA Community or Eclipse; VS Code with Java extensions is also possible

## Database setup
Open MySQL Workbench or the MySQL command line and run:

```sql
CREATE DATABASE invotracker CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'invotracker_app'@'localhost' IDENTIFIED BY 'choose-a-long-unique-password';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, REFERENCES
ON invotracker.* TO 'invotracker_app'@'localhost';
FLUSH PRIVILEGES;
```

Set environment variables in PowerShell (replace the example password):

```powershell
$env:DB_URL="jdbc:mysql://localhost:3306/invotracker?serverTimezone=UTC"
$env:DB_USERNAME="invotracker_app"
$env:DB_PASSWORD="choose-a-long-unique-password"
```

## Run locally
From the project folder:

```powershell
mvn spring-boot:run
```

Open http://localhost:8080

Run tests:

```powershell
mvn test
```

If `mvn` is not recognized, install Maven or open/import this project in IntelliJ IDEA and run `InvoTrackerApplication`.

## Main API endpoints
All endpoints except registration, login, CSRF initialization and static files require a logged-in session.

- `GET /api/csrf` — initialize/get CSRF token
- `POST /api/auth/register` — create business account
- `POST /api/auth/login` — authenticate and create session
- `GET /api/auth/me` — current account
- `POST /api/auth/logout` — end session
- `GET /api/invoices` — list current owner's active invoices
- `POST /api/invoices` — create invoice
- `PUT /api/invoices/{id}` — update invoice
- `POST /api/invoices/{id}/payments` — record a payment
- `DELETE /api/invoices/{id}` — cancel invoice if no payment was recorded
- `GET /api/invoices/summary` — dashboard metrics
